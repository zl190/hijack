查看安装命令 ↗
CURL
curl -fsSL https://raw.githubusercontent.com/zl190/hijack/main/install.sh | sh
或使用 HOMEBREW
brew install --cask zl190/tap/hijack

首次使用，在系统设置 → 隐私与安全性 → 辅助功能中开启 Hijack。点菜单栏图标可设置快捷键。

语音由谁处理？

由你使用的语音工具处理。Hijack 不录音，也不保存或上传音频。语音数据如何处理，请查看对应工具的隐私政策。
