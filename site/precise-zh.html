安装 Hijack

先装好微信输入法，设置「按键说话」快捷键。再选下面一种方式安装 Hijack。

查看安装命令 ↗
CURL
curl -fsSL https://raw.githubusercontent.com/zl190/hijack/main/install.sh | sh
或使用 HOMEBREW
brew install --cask zl190/tap/hijack

首次使用，在系统设置 → 隐私与安全性 → 辅助功能中开启 Hijack。默认使用微信输入法的语音键，也可以点菜单栏图标更换。

查看发布版本 ↗
语音由谁处理？

微信输入法。Hijack 只负责切换输入法和转发按键，不录音，也不保存或上传音频。语音数据如何处理，请查看微信输入法的隐私政策。
