Before you start

The current source build implements the WeType voice example. Translation and text capture are concepts.

  • Install WeType and set its push-to-talk voice key.
  • Install Xcode Command Line Tools.
  • Have the Hijack source checked out and open its folder in Terminal.
RUN FROM YOUR HIJACK FOLDER
./install.sh

The script builds and opens /Applications/Hijack.app. On first launch, allow Hijack in System Settings → Privacy & Security → Accessibility.

Need the build tools?

Run xcode-select --install in Terminal, then follow the system installer.

Where are the settings?

Click the hat in your menu bar to set your trigger, launch at login, and language. If the icon is hidden, open Hijack again to reach its settings.

Who processes my voice?

Hijack switches input sources and forwards trigger-key events. WeType processes the speech; its own policies govern how that voice data is handled.
