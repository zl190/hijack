Install Hijack ↗

Ready to run

Install the prebuilt app with either command below. No source checkout or developer tools needed.

  • An Apple silicon Mac running macOS 13 or later.
  • WeType installed, with its push-to-talk voice key set.
INSTALL WITH CURL
curl -fsSL https://raw.githubusercontent.com/zl190/hijack/main/install.sh | sh

OR, IF YOU USE HOMEBREW
brew install --cask zl190/tap/hijack

The curl installer downloads the latest GitHub release into /Applications/Hijack.app and opens it. On first launch, allow Hijack in System Settings → Privacy & Security → Accessibility.

The current release supports the WeType voice example. Translation and text capture are concepts.

View releases on GitHub ↗
Where are the settings?

Click the hat in your menu bar to set your trigger, launch at login, and language. If the icon is hidden, open Hijack again to reach its settings.

Who processes my voice?

Hijack does not record, store, or upload audio. It switches input sources and forwards trigger-key events. WeType handles speech recognition; consult its privacy policy for audio processing, network transfer, and retention.
