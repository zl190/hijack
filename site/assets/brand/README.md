# Hijack wordmark

The product name is **Hijack**. The trailing dot belongs to the visual wordmark only.

- `hijack-wordmark.svg`: dark wordmark on a light background.
- `hijack-wordmark-inverse.svg`: light wordmark on a dark background.
- All glyphs are vector paths, so no font installation is required. Preserve the aspect ratio and leave at least half the capital H height around the mark.
- Ink: `#252923`; paper: `#f5f3ee`; dot: `#a44830`. Do not independently stretch, move or recolor the dot.

The wordmark preserves the approved system-font treatment (weight 730, tracking −1px at 27px). The homepage header uses the SVG as its source; application and repository names omit the dot. `../og.png` is the 1200×630 sharing image derived from this mark and the approved app icon.
