## Hijack 1.1.3

- **Lighter while you dictate.** Hijack looked up the voice tool's processes every 50 ms while waiting for the text; it now does it once per dictation. Measured with Instruments: Hijack's CPU use went from 16 to about 5 ms per second, with no main-thread hangs.
- **One state machine decides what a key press does.** Holding, tapping, hands-free, "any key stops" and the voice tool's own key now go through one tested table instead of scattered flags. Same behavior, now covered by tests.
- **Timing marks for Instruments.** Each dictation shows up under Points of Interest with its phases (starting, listening, waiting for text), so you can see where the time goes.
