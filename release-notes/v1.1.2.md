## Hijack 1.1.2

- **Steadier key handling.** Hijack's key listener no longer reads settings files, queries other apps or writes the log while a key is in flight. Slow work there could make macOS pause the listener, and the voice tool could then miss its talk key.
- **Recovers after the listener is paused.** If macOS pauses it, Hijack checks the shortcut's real state when it resumes, so a missed release can't leave the talk key held or ⌥ stuck down.
- **A clearer log.** One line per dictation (`hijack log`), saying whether the talk key went out, whether the voice tool started listening, and whether its window appeared. The step-by-step detail is in `hijack log --live`. The log file stays under 1 MB.
