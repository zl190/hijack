## Hijack 1.1.1

- **Reopens itself after an update.** When an installer replaces Hijack (Homebrew, the curl script, or a source build), it starts again on its own. Homebrew can't do this itself: its install sandbox doesn't allow launching apps.
  - It's a small launchd job that runs only when Hijack's app file changes, then exits. Quitting Hijack never restarts it.
  - macOS shows it once as a background item under Login Items & Extensions.
- Updating from 1.1.0, open Hijack once more by hand; the updates after that reopen it automatically.
