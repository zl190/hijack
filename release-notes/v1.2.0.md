## Hijack 1.2.0

- **Updates inside the app.** Hijack checks for a new version once a day and asks before it installs one. "Check for Updates…" is in the menu. Settings › General has the two switches: automatic checks, and automatic download and install. This release cannot update itself from 1.1.4; the first in-app update is 1.2.0 to 1.2.1.
- **`hijack version` names the update it found.** The command prints the running version and, after a check, the newer version.
- Built with Sparkle 2.10.0, pinned by checksum.
